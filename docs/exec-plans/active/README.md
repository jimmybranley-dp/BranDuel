# Active execution plans

Place active, scoped implementation plans here. A plan should link to the relevant contract, name its acceptance checks, and move to `../completed/` only after verification. There are no active plans in this repository-local map.

Use [the lightweight template](../PLAN-TEMPLATE.md) for multi-module, data-sensitive, or multi-session work. The execution-plan checker rejects incomplete plans but does not require a plan for a tiny isolated fix or documentation-only change.
